# tyt-calculator

A simple Python console application to calculate TYT net scores and placement points.

TYT Net and Score Calculator / TYT Net ve Puan Hesaplayıcı

---

🇬🇧 **English**

A simple Python console application to calculate Turkish Higher Education Entrance Exam (TYT) net scores and placement points.

### Features
* Net calculation based on correct/wrong answers (4 wrong answers deduct 1 correct answer).
* Includes OBP (High School Graduation Score) weight calculation.
* User-friendly terminal interface with built-in delay effects.

### Technologies
* Python 3.x

---

🇹🇷 **Türkçe**

TYT net puanlarını ve yerleştirme puanlarını hesaplamak için basit bir Python konsol uygulaması.

### Özellikler
* Doğru/yanlış cevaplara dayalı net hesaplama (4 yanlış 1 doğruyu götürür).
* OBP (Lise Mezuniyet Puanı) ağırlık hesaplamasını içerir.
* Yerleşik gecikme efektlerine sahip kullanıcı dostu terminal arayüzü.

### Teknolojiler
* Python 3.x

### Nasıl Çalıştırılır
Bir terminalden `python tyt_calculator.py` dosyasını çalıştırın.

```bash
python tyt_calculator.py
